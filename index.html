Deploy to Firebase Hosting

Follow these steps to host this Web App on **Firebase Hosting** with SSL (HTTPS) for full Web Bluetooth support.

1 Install Firebase CLI

Open Terminal/Command Prompt and install Firebase Tools:

npm install -g firebase-tools
2 Prepare Local Folder

Create a project folder (e.g., whisprx-app), save this web code as public/index.html inside it.

3 Login & Initialize

Run these commands in your project folder:

firebase login

firebase init hosting

Select your Firebase project and set public as public directory.

4 Deploy Live
firebase deploy

Bluetooth Connection Guide

Why won't a paired ESP32 connect?

  1. Unpair from Phone/PC Settings First: Go to your phone's Bluetooth settings, find "ESP32_Pillbox", and tap Unpair / Forget Device. If your phone is connected at the system level, Web Bluetooth cannot grab the BLE connection.
  2. Turn On Phone Location: On Android, Google Chrome requires Location / Nearby Devices permission to perform Web Bluetooth scans.
  3. Use Supported Browser over HTTPS: Use Chrome, Edge, or Opera. Web Bluetooth requires HTTPS or `http://localhost`.
